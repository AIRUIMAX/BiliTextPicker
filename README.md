## 这是什么

字幕是视频里信息密度最高的东西。把字幕抠出来交给大模型，可以顺手完成很多事：

- **长视频摘要**：一小时的技术分享，30 秒读完核心结论
- **值不值得看**：先看大纲再决定要不要花时间
- **翻译 / 术语提取 / 知识卡片**：把口播内容转成可检索、可复用的笔记
- **检索与对比**：多个视频的字幕放到一起找差异

问题是 B 站没有字幕导出的入口。这个扩展只做一件事，并且做干净：**纯本地运行，不经过任何第三方服务器**，拿到字幕后一键复制或下载。

## 功能

| 功能 | 说明 |
| --- | --- |
| 一键提取字幕 | 打开视频页点一下图标即可，字幕按时间轴列在面板里 |
| 复制到剪贴板 | 纯文本一行一句，直接粘给 ChatGPT / Claude / DeepSeek 就能总结 |
| 下载 TXT | 自动命名为 `视频标题_分集名.txt`，文件名非法字符自动替换 |
| 多版本字幕切换 | 官方字幕、AI 自动生成字幕、翻译字幕在下拉框里自由切换 |
| 多分集支持 | 自动识别当前播放的分集，字幕不会张冠李戴 |
| 番剧 / 短链支持 | 番剧播放页、`b23.tv` 短链跳转后都能正常识别 |
| 🎚 音量增强（附加） | 滚轮在播放器区域直接调音量，最高 **500%**，突破 B 站 100% 上限；`↑` / `↓` 方向键同样可用 |
| 🎨 控制栏美化（附加） | 把 B 站播放器控制栏的文字与图标改为亮白色，暗色背景下更清晰 |

> 附加的两个播放器功能是作者自用的顺带产物，默认常开，不影响字幕提取。

## 安装

### 方式一：下载 Release（推荐，最省事）

1. 到 [Releases](https://github.com/AIRUIMAX/BiliTextPicker/releases/latest) 下载 `BiliTextPicker-v1.0.0.zip` 并解压
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`），打开右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择解压出来的 `BiliTextPicker-v1.0.0` 文件夹
4. 打开任意 B 站视频页，点击工具栏里的扩展图标（建议在扩展页固定图标）

### 方式二：从仓库加载

下载本仓库（`Code` → `Download ZIP`，或 `git clone`）并解压，第 3 步选择仓库里的 **`dist`** 文件夹。

> ⚠️ 未上架应用商店。Windows 稳定版 Chrome 会拦截非商店来源的 `.crx`，所以**只能通过「开发者模式加载」这一种方式安装**，`.zip` 不能直接拖进浏览器。

## 使用

1. 打开一个**有字幕**的 B 站视频（例如 `https://www.bilibili.com/video/BVxxxxxxxxxx/`）
2. 点击扩展图标，面板会显示当前视频标题、分集名与字幕条数
3. 需要的话在 **字幕语言** 下拉框里换一个版本
4. 点击 **复制字幕** 或 **下载字幕**
5. 粘贴给 AI，附上一句提示词即可

推荐的提示词模板：

```
以下是一个视频的字幕文本（按时间顺序，一行一句）。请：
1. 用 5 句话总结核心内容
2. 输出一份带层级的知识大纲
3. 列出 3 个最值得深入的点，并说明原因

字幕：
<在这里粘贴>
```

**其他按钮**

- **刷新字幕**：重新加载当前标签页并重新抓取，用于切换分集后字幕没跟着变的情况
- **下载字幕**：文件默认落在浏览器的下载目录，只含正文、不含时间码（时间码会白白占用 AI 的上下文）

## 常见问题

**Q：提示「该视频没有字幕」？**
A：B 站字幕有两个来源 —— UP 主手动上传的 CC 字幕，以及站方 AI 自动生成的字幕，两者都需要 UP 主或站方开启才存在。请先在网页播放器里确认能打开字幕面板。

**Q：字幕列表是空的 / 只有一种语言？**
A：先登录 B 站账号再刷新页面。翻译字幕和部分 CC 字幕要求登录，且**需要在播放器里把字幕打开过一次**才会出现。

**Q：提示「扩展未激活，请刷新页面」？**
A：常见于扩展刚加载、或页面早于扩展打开。刷新页面即可。

**Q：多分集视频的字幕对不上？**
A：先确认地址栏里的分集参数与正在播放的分集一致，再点「刷新字幕」。

**Q：复制按钮没反应？**
A：剪贴板需要页面焦点，先把鼠标移回面板再点；仍失败就直接「下载字幕」拿 TXT。

**Q：音量增强会不会把声音弄坏？**
A：它接管的是播放器的音频输出，音量以浮层里的百分比为准。若同时装了其他改音频的扩展可能相互冲突。刷新页面即恢复默认。

**Q：直播页面能用吗？**
A：能注入、能音量增强，但直播没有字幕数据，字幕功能不适用。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `activeTab` / `scripting` | 读取当前标签页标题、按需注入内容脚本 |
| `storage` | 预留扩展设置存储 |
| `cookies` | 部分字幕（尤其是 UP 主上传的 CC 字幕、翻译字幕）需要登录态才能读取 |
| `downloads` | 预留（当前下载不依赖该权限） |
| B 站域名访问 | 读取视频信息与字幕文件 |

扩展**不收集、不上传、不存储**任何用户数据；所有网络请求都直接发往 B 站官方接口，没有作者自己的服务器。
